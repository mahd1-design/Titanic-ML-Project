Titanic Survival Prediction 🚢

Project Overview

This project uses Machine Learning to predict whether passengers survived the Titanic disaster.

Dataset

The dataset comes from the Kaggle Titanic competition.

Project Steps

* Exploratory Data Analysis (EDA)
* Data Preprocessing
* Feature Engineering
* Training and Evaluating Machine Learning Models
* Hyperparameter Tuning
* Generating Kaggle Predictions

Machine Learning Models

Model	Validation Accuracy
Logistic Regression	80.45%
Random Forest	82.12%
XGBoost	80.45%
Tuned Random Forest	81.01%

Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* XGBoost
* Jupyter Notebook

Results

Random Forest achieved the highest validation accuracy of 82.12% among the models tested.
